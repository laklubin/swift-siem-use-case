Control references: SWIFT Customer Security Programme — Customer Security Controls Framework (CSCF), objectives 1–7, covering environment protection, access control, and detect/respond. PCI DSS v4.0.1 — Requirements 1–12, PCI Security Standards Council. Mapping a detection to a control is an engineering aid, not an attestation: your assessor scopes and judges compliance, and a single use case rarely satisfies a control on its own. Sample logs are synthetic — they are written in the shape the named product emits so a rule can be drafted and unit-tested, but field names, formats and message types vary by version, parser and local configuration, so validate every one against your own telemetry before deploying. Hostnames, BICs, IBANs, account numbers, IP addresses, card BINs and operator IDs in the samples are fabricated. Compiled by LK for payment assurance and detection engineering reference.
